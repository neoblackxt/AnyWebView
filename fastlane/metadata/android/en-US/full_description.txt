<p><b>Requires an Xposed framework hooking the system framework</b> (e.g. LSPosed, or a framework built into your ROM). <b>Root is NOT required.</b></p>
<p><i>AnyWebView</i> is an Xposed module that lets you select the WebView to be used. A webview app must be installed for all users (or in all spaces) to be selectable.</p>
